## 🇧🇷 Português

### 🌿 Visão Geral & Filosofia de Design
**TERRÆ** (*do latim "da Terra"*) combina design editorial de alta classe, fotografia documental de natureza, tipografia assimétrica e microinterações de alta precisão.

- **Variância Editorial:** Composições assimétricas em grid combinando *Cormorant Garamond* (Serifa Display) e *Outfit* (Sans-serif).
- **Acervos Interativos:** Explore 8 biomas continentais, fichas de espécies em alta definição, dualidade de escalas (micro vs. macro) e acervo fotográfico.
- **Motion & Transições:** Rolagem fluida com física customizada (`easeOutExpo`), cursor interativo contextual, menu overlay em tela cheia com entrada staggered e revelação dinâmica no hover.

### 🛠 Tecnologias Utilizadas
- **Framework:** [Next.js](https://nextjs.org/) (App Router, Turbopack)
- **Linguagem:** TypeScript
- **Estilização:** Tailwind CSS & Sistema de Tokens CSS Personalizado
- **Fontes:** Cormorant Garamond, Outfit, JetBrains Mono
- **Deploy:** [Vercel](https://vercel.com/)

## 🇬🇧 English

### 🌿 Overview & Design Philosophy
**TERRÆ** (*Latin for "of the Earth"*) blends high-end editorial design, documentary nature photography, asymmetric typography, and high-precision micro-interactions.

- **Editorial Variance:** Asymmetric grid compositions featuring high-contrast pairing of *Cormorant Garamond* (Display Serif) and *Outfit* (Sans-serif).
- **Interactive Archives:** Explore 8 continental biomes, high-definition species profiles, macro vs. micro scale duality, and photographic archives.
- **Motion & Transitions:** Smooth eased scrolling (`easeOutExpo`), custom contextual cursor states, staggered fullscreen overlay navigation, and hover reveals.

### 🛠 Tech Stack
- **Framework:** [Next.js](https://nextjs.org/) (App Router, Turbopack)
- **Language:** TypeScript
- **Styling:** Tailwind CSS & Custom CSS Token System
- **Fonts:** Cormorant Garamond, Outfit, JetBrains Mono
- **Deployment:** [Vercel](https://vercel.com/)
